# 🔗 Advanced Linking & Note Embeddings

This note demonstrates how to connect ideas seamlessly using Obsidian's link syntax.

## 🎯 Custom Link Aliases
* You can link to a note but change the text that shows up using a pipe (`|`) character.
* *Example:* Read the full details in our `[[note_metadata_template|UI Spec Document]]`.

## 📥 Live Note Embedding (Transclusion)
By adding an exclamation mark `!` in front of an internal link, Obsidian will pull the actual content of that note and display it live inside this note:
